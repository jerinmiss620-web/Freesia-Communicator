# Freesia Messenger · 通讯侠 v0.3.36 (Test)

## 样式所有权与隔离

- 手机窗口样式只注入通讯侠 Shadow DOM，不再把整份手机 CSS 追加到酒馆页面的 `head`。
- 不支持 Shadow DOM 的回退路径也把手机样式放在独立 root host 内，不向酒馆页面全局注入。
- 扩展折叠面板使用独立、仅以扩展根节点为作用域的样式表。
- 删除扩展复选框的专属 input 规则；不设置其 appearance、accent-color、背景、边框、圆角、阴影或尺寸。复选框外观由酒馆主题决定。
- 手机窗口内部的 checkbox/radio 规则保留在 Shadow DOM 内，酒馆主题无法穿透影响。

## 全屏与窗口尺寸

- 删除手机窗口基础规则中的 `max-width: min(520px, calc(100vw - 16px))`，避免 CSS 视口与 JS 定位视口不一致时产生 16px 的宽度裁切和偏移。
- 删除依赖覆盖的移动端 `max-width: none`；不再设置冲突的基础上限与媒体查询覆盖。
- PC 端窗口宽度仍由窗口控制器计算，默认约 420px，最大 520px；手机端宽高继续使用 Visual Viewport 的实际尺寸。

## 保留项目

- 保留 v0.3.35 已加入的 iOS 键盘安全区处理、底部额外 5px 删除，以及单条消息重试提示的持久关闭按钮。
- 保留原通讯侠脚本 ID、业务存储键、聊天元数据和现有功能，不迁移或清除用户数据。
- 本版本只在测试分支提供，尚未宣称通过 iPhone / TT 实机验收。
