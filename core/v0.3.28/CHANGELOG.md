# Freesia Messenger · v0.3.28

## Remote Loader 首次接管流程补全

- 在现有扩展折叠栏的远程更新区域加入「接管当前版本」操作；当 Loader 检测到已有 Core 尚未建立自动恢复授权时显示。
- 接管前由 Loader 从 Test 清单的固定历史 Commit 下载当前运行版本源码，验证 SHA-256 与 UTF-8 字节长度，写入并回读校验 Last Known Good。
- 接管完成后，用户停用原独立 Core 脚本并刷新，Loader 才会负责自动恢复与后续更新。
- 安装更新按钮在需要接管时保持禁用，避免跳过回滚保护。
- Core 宿主定位统一为 Tavern Helper 直接父窗口，与 TLE Bootstrap / Loader 的宿主契约一致。

## 保持不变

- 不修改通讯数据结构、聊天记录、订阅、动态、预设或任何现有存储键。
- 不新增独立悬浮球、第二个更新窗口或额外管理入口。
- 更新控制继续位于通讯侠现有扩展折叠栏。
