# Freesia Messenger · 通讯侠 v0.3.38

## 新增：移动端窗口尺寸选项

- 在酒馆助手「通讯侠」现有扩展折叠内容中增加「移动端窗口尺寸」设置，不新增独立入口，也不放入 TLE 折叠侠。
- 默认保持 100% 全屏；可选 90% 视口尺寸，窗口水平与垂直居中，并恢复圆角、边框和轻阴影。
- 选择自动保存，刷新或重新加载通讯侠后保留。
- 只作用于移动端窗口布局；PC 端窗口尺寸、拖动、缩放与最大化逻辑不变，悬浮球位置和尺寸也不受影响。
- 90% 模式沿用现有 Visual Viewport 尺寸计算，窗口随移动端可视区域变化重新布局。

## 发布与兼容

- 正式 Core：`0.3.38`；最低 Remote Loader：`0.1.9`；Permanent Bootstrap：`1.0.8`。
- 保留现有 Core API、聊天记录、用户设置及业务存储键。
- 不需要清除酒馆站点数据。

## 验收

- Bootstrap 1.0.8 已在 TT 实机完成更新链验收，加载成功且速度正常。
- 移动端 90% / 100% 窗口行为仍应在 TT、ST 与 iPhone Safari 分别回归；PC 端保持原有尺寸行为。
