# Freesia Messenger · v0.3.24

## 窗口层重构

- 宿主窗口定位改为逐层检查可访问的父窗口，优先识别 SillyTavern API、原生正则容器或 `#sheld`，不再直接假定脚本的直接父窗口就是酒馆主页面。
- 通讯侠主窗口与可拖动悬浮入口统一挂载到同一个 Shadow DOM，采用与正则侠相同的隔离式窗口挂载思路。
- 主窗口内部样式在 Shadow DOM 内加载，降低酒馆主题和第三方全局 CSS 对窗口、按钮及表单控件的干扰；扩展菜单控制区仍由宿主文档样式管理。
- 保留主窗口与悬浮入口各自的拖动、位置记忆、最小化、恢复和关闭行为。
- 修正 Shadow DOM 环境下消息编辑器焦点恢复的活动元素判断。
- 兼容清理旧版直接挂载的窗口、悬浮入口和旧父窗口实例。

## 保持不变

- 保留 v0.3.23 的业务功能、聊天记录结构、动态与订阅数据结构、预设、设置键及正文同步 Prompt ID。
- 保留 821px 以下全屏布局和现有安全区域处理。
- 本版本仅更新 Test 通道；Stable 仍为 v0.3.22。

## 验证说明

- 已完成 JavaScript 语法解析检查。
- 已核对提交源码的 UTF-8 字节长度与 SHA-256。
- 本版本仍需在 PC SillyTavern、Android、iPhone/TavernTogether 实机验证后，才能考虑提升到 Stable。
