# Freesia Messenger · 通讯侠 v0.3.35

## iPhone 键盘与底部安全区

- 增加移动端文本输入焦点与 Visual Viewport 高度检测。
- iOS 软件键盘打开时临时取消 Home Indicator 底部安全区占位；键盘关闭后恢复设备安全区。
- 移除手机底栏额外的 5px 底部偏移，保留实际安全区高度。
- 不改变窗口定位算法；保留已验证的 Visual Viewport 定位路径。

## 手机全屏布局

- 在 821px 以下的移动端媒体查询中解除桌面基础规则的 `max-width` 限制。
- 桌面端窗口宽度、缩放和最大化规则保持不变。

## 消息交互

- 失败、停止或未完成的角色回复提示增加独立关闭按钮。
- 关闭状态按单条用户消息持久保存，不删除消息、不改变发送状态。
- 再次重试或编辑重发时重置关闭标记；若新一轮仍失败，提示可再次出现。

## 样式隔离

- 手机窗口内部控件样式仅作用于 Shadow DOM 根节点。
- 扩展折叠面板不再接收通讯侠私有主题变量、颜色模式或复选框/选择框外观。
- 扩展面板复选框与选择框交还酒馆主题；仅保留必要的排列尺寸规则。

## 兼容性

- 保留原通讯侠脚本 ID、业务存储键、聊天元数据结构和既有数据。
- 不引入 Bootstrap、Remote Loader 或 IndexedDB 依赖。
- 现有 GitHub Direct 导入入口无需重新导入；本体更新由 `core/current/Freesia-Messenger.js` 提供。
